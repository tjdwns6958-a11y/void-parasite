# 공허 기생충 — 세계·생명체 구상 (2026-11-23, v118 기준)

## 0. 큰 줄기
- **1스테이지 = 공허 밖(밝음)** → **2스테이지 = 잠식(경계, 공허가 스며듦)** → **3스테이지부터 = 공허(지금까지 만든 것)**.
- 핵심 이야기: 공허 고유 생물만이 아니라 **바깥에서 들어온 생물이 공허에 적응해 가는 모습**. 나중에는 공허가 문명을 흡수.
- 설계 원칙: 바깥 생물마다 **원형(1) → 잠식형(2) → 공허 적응형(3)** 세 모습이 있다. 1스테이지에서 익힌 패턴이 2·3스테이지에서 비틀려 나와, 플레이어가 '같은 생물이 변했다'는 걸 몸으로 느끼게 한다.
- 지금 있는 공허 생물을 바깥 생물의 '적응형'으로 이어 붙이면 세계관이 한 줄로 꿰어진다(아래 ★ 표시).

## 1. 지역 흐름 (루트) — 판마다 1스테이지 출구에서 루트를 고르는 식
| 루트 | 1 · 바깥 | 2 · 잠식 | 3 · 공허 |
|---|---|---|---|
| 수정 동굴 | **수정 동굴** — 밝은 결정, 지하수 웅덩이, 결정에 반사되는 빛 | **공허 정동** — 결정 속에 공허가 갇혀 보라로 탁해짐, 금이 간 결정 벽 | **공허 결정 심연** — 정동 집게왕의 동굴 |
| 기계 문명 | **기계 도시 하층** — 증기 배관, 톱니, 따뜻한 등불, 레일 | **잠식된 공장** — 전선이 핏줄처럼 맥박, 기계가 살처럼 꿈틀 | **공허 기계 심장** — 기계와 공허가 한 몸 |
| 숲 | **발광 숲** — 이끼, 반딧불, 큰 버섯 | **잠식된 숲** — 나무가 비틀리고 열매가 눈알, 그림자가 늦게 따라옴 | **공허 산호 숲** ★지금 2구역 |
| 호수·바다 | **지하 호수·석호** — 맑은 물, 물결 빛 | **검은 해안** — 물이 검어지고 조수가 거꾸로 흐름 | **공허 소용돌이 바다** ★지금 소용돌이 |

## 2. 공허 밖 생명체 (원형 → 잠식형 → 공허 적응형)
### 수정 동굴 루트
- **석영 게** — 원형: 등의 수정에 빛을 모아 반사광을 쏨(빛 줄기 피하기) / 잠식형: 수정이 탁해져 빛 대신 '그림자 광선'(맞으면 시야가 좁아짐) / 적응형: 등의 정동이 작은 균열이 되어 새끼를 방 다른 곳으로 순간 이동 → ★정동 집게왕의 무리
- **종유 박쥐** — 원형: 천장에 매달렸다가 초음파 파문(퍼지는 고리)으로 찾고 급강하 / 잠식형: 파문이 보이는 고리가 되어 닿으면 끌려감 / 적응형 **메아리 아귀**: 날개막으로 공간을 접어 메아리 분신을 남김(진짜는 하나)
- **광석 두더지** — 원형: 땅속을 다니며 결정을 먼저 먹어 치움(먹이 경쟁) / 잠식형: 지나간 굴이 잠깐 공허 균열 함정으로 남음 / 적응형 → ★**땅울음**
- **동굴 도롱뇽** — 원형: 웅덩이 근처에서 꼬리를 끊고 재생 / 잠식형: 재생할 때마다 몸이 하나 더 갈라짐 / 적응형 **분열 도롱뇽**: 갈라진 몸끼리 실로 이어져 있고 실을 물면 둘 다 아픔

### 기계 문명 루트
- **청소 거미 드론** — 원형: 정해진 길을 순찰, 탐조등에 걸리면 경보 → 주변 로봇이 모임(잠입) / 잠식형 **녹슨 거미**: 관절에 공허 살이 붙어 길을 벗어나 불규칙하게 움직임 / 적응형 **껍데기 사냥꾼**: 기계 껍데기만 남고 안의 공허 생물이 다른 껍데기로 갈아탐(주인공 기생충과 거울 같은 존재)
- **증기 일꾼** — 원형: 증기 분출 원뿔, 열기로 벌레를 쫓음 / 잠식형: 증기 대신 보라 안개(시야 가림) / 적응형 **공허 용광로**: 몸속 소용돌이가 먹이와 플레이어를 빨아들임
- **전선 뱀** — 원형: 늘어진 케이블이 꿈틀, 바닥에 전류 구역 / 잠식형: 케이블이 핏줄처럼 맥박치며 해류처럼 끌어당김 / 적응형 **신경망 뱀**: 방 전체 전선이 한 몸, 머리를 찾아 물어야 함
- **태엽 쥐 떼** — 원형: 무리로 다니다 태엽이 풀리면 멈춤(먹을 기회) / 잠식형: 태엽 대신 공허 심장이 박혀 멈추지 않음 / 적응형 → ★**한 몸의 무리**(최종 보스 복선)
- **탐조등 감시기** — 적응형 → ★**감시자**(심연의 감시탑)

### 숲 루트
- **반딧불 나방** — 원형: 빛가루로 어두운 곳을 밝힘(길잡이) / 잠식형: 빛가루가 보라 포자가 되어 닿으면 둔화 / 적응형 → ★**빛 포자**
- **뿔사슴벌레** — 원형: 큰 뿔로 직선 돌진 / 잠식형: 뿔이 결정 낫으로 변함 / 적응형 → ★**낫그늘**
- **덩굴 두꺼비** — 원형: 혀로 끌어당기고 점프 / 잠식형: 혀가 촉수로 갈라짐 / 적응형 → ★**제르사이 유생**
- **이끼 거북** — 원형: 등의 이끼 정원에 먹이가 자람(느리고 순함, 따라다니면 이득) / 잠식형: 등 정원이 공허 산호로 바뀜 / 적응형 → ★**가시 산호충·산호 여왕**의 기원

## 3. 공허 안 생명체 (지역별)
### 공허 소용돌이 바다 (해류)
- **공허 칠성장어** ★있음 — 반투명, 물고 도망
- **해류 가오리** — 해류를 타고 넓게 활강, 지나간 자리에 해류 방향이 바뀌는 '물결 꼬리'
- **커튼 해파리** — 촉수 커튼이 해류 방향으로 늘어짐, 해류가 맥박칠 때 커튼이 휩쓸림
- **공허 고래(배경 생물)** — 방 밖을 지나가면 모든 해류가 한쪽으로 쏠리는 환경 이벤트
- **소용돌이 말미잘** — 소용돌이 출구에 숨어 있다가 나오는 순간 물기
- **해류 정어리 떼** — 먹이. 해류 따라 흘러 다니는 무리

### 공허 절벽·협곡
- **절벽 따개비** — 벽에 붙어 있다가 지나가면 침을 쏨(벽 쪽이 위험)
- **활강 막충** — 협곡 바람골을 따라 활강하다 급강하
- **현수 거미** — 협곡 사이 실 다리를 놓음, 다리를 끊으면 위의 것이 떨어짐
- 지형 기믹: **낭떠러지**(가장자리에서 밀리면 아래층으로 떨어짐) · **상승 기류**(공허 바람이 한쪽으로 밂) · **무너지는 발판**

### 기존 지역
- 둥지·번식지: 공허 고유종(유충, 보이드링) — '공허가 원래 살던 곳'으로 남김

## 4. 그 밖의 지역 아이디어
- **가라앉는 거리** — 흡수된 도시. 건물이 반쯤 공허에 잠겨 있고 방 일부가 천천히 꺼짐
- **메아리 회랑** — 흡수된 생물의 그림자(옛 모습)가 같은 행동을 되풀이. 공허가 문명을 삼킨 흔적을 보여 줌
- **공허 양식장** — 공허 생물이 바깥 생물을 '기르며' 잠식시키는 곳(흡수 과정 자체를 보여 줌)
- **거꾸로 숲** — 뿌리가 천장으로 자란 숲, 천장에서 열매·생물이 떨어짐
- **뼈 평원** — 공허에 녹은 거대 생물의 화석 위. 갈비뼈 사이가 길
- **검은 조수 웅덩이** — 바다와 해안 경계. 밀물·썰물 주기로 길이 열리고 닫힘
- **무중력 별빛 지대** — 최종 보스 근처, 떠다니며 움직임이 미끄러짐

## 5. 게임 구조 제안
- 1스테이지 출구를 2개(예: 수정 동굴 / 기계 도시)로 나눠 루트를 고름 → 판마다 다른 생물·보스.
- 2스테이지 방에는 **반쯤 잠식된 생물**(반은 원형, 반은 공허)과 **잠식 이벤트**(바깥 생물이 공허 균열에 닿으면 그 자리에서 잠식형으로 변이)를 넣어 '흡수'를 눈으로 보여 줌.
- 같은 생물의 세 모습은 같은 뼈대(공격 패턴)에 변주를 더해 학습이 이어지게 함.
