공허 기생충 이야기형 구조

숲 → 기계 문명 → 수정 동굴 → 실험실 → 공허로 이어지는 짧고 완결된 이야기 게임이 지금 장르와 맞는지 따져 보고, 장(章) 하나의 지도와 메인 퀘스트를 어떻게 짤지 그림으로 보인다.

잘 맞는다. 장르 이름으로는 '탑다운 액션 어드벤처 + 로그라이트 요소'가 된다.

위에서 보는 한 화면 방 전투, 기믹을 찾아 깨는 보스, 몸이 변하는 성장은 이야기형 액션 어드벤처의 핵심 재료와 같다. 바뀌는 것은 '판마다 처음부터'가 '장마다 이어서'로 바뀌는 것 하나다. 장 안의 일반 방을 지금처럼 무작위로 두면 로그라이크의 다시 하는 맛도 남는다.

장르 지도에서 어디로 옮겨 가나

그대로 살아나는 것한 화면 방 전투, 기믹 보스, 진화·탈피, 퀘스트 창, 엔딩 2개
새로 생기는 것장 단위 저장과 이어하기, 고정 이야기 방, 메인 퀘스트 사슬, 짧은 대사와 기록 조각
조심할 것다시 할 이유가 줄어든다. 엔딩 분기, 계통 빌드, 숨은 기록, 일반 방 무작위로 채운다
