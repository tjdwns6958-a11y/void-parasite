계통(포식·갑각·공허) 퀘스트 창 시안 3안 + 화면 맨 밑 경험치 막대

실제 게임 화면 (v42 코드로 찍음). 먹는 방식은 지금처럼 물기 + 섭취, UI 모양도 지금 방식 그대로. 바뀐 것은 계통 표시 자리·모양과 경험치 막대 자리.

세 안 공통 — ① 오른쪽 위의 작은 고리 셋 + '유기·무기·정수' 줄 → 에너지 막대 밑 퀘스트 창으로 옮김 (계통마다 자기 재료를 같이 보여 줌: 포식 = 유기물, 갑각 = 무기물, 공허 = 공허 정수) ② 계통마다 그림 기호 송곳니 · 육각 껍질 · 눈 ③ 상태를 말로: 진행 중 '12 / 20' · 탈피 가능!(초록 깜빡임) · 다른 계통 1단계 필요 · 한계 · 완성(금색) ④ 퀘스트 창을 누르면 진화 나무 ⑤ 오른쪽 위는 구역 · 변이 횟수 · 지도만 ⑥ 경험치 막대는 화면 맨 밑 가로 전체 (메이플식, 'Lv.3 · 경험치 27 / 44 [61.36%]')
