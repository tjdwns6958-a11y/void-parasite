게임 시작 연출 시안 3안 (S1~S3)

지금: 켜자마자 진화 나무 설명서가 뜨고 '화면을 누르면 시작' → 조작 안내 글. 제목·이야기 없이 설명부터 나옴. 세 안 모두 누르면 건너뛰기, 두 번째 판부터는 짧게(2초). 진화 나무는 시작 때 띄우지 않고 퀘스트 창을 누를 때만.

Claude 의견: S3. 시작에 보여 준 '한 몸의 무리'를 마지막에 다시 만나고, 엔딩 '공허에 남는다 / 밖으로 나간다'가 '무리로 돌아갈까 / 벗어날까'로 이어져 이야기가 한 바퀴 돈다. 최종 보스의 무리 엔진(점 수백 개가 모양을 만듦)을 그대로 써서 만들기도 수월. S1의 '첫 퀘스트로 조작 배우기'는 어느 안에든 붙일 수 있음.
